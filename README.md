# SINV-codon-analysis

This repository contains the data, analysis scripts, and results for the codon usage analysis of Sindbis virus (SINV).

## Repository Structure

- `data/` : Sequence data used for the analyses.
- `scripts/` : R and Python scripts for sequence extraction, codon usage indices (e.g., RSCU, ENc, CAI, RCDI, RAD, COA), and statistical analyses.
- `results/` : Output tables and figures generated by the scripts.

## Software and Dependencies

Analyses were performed in R (version 4.x.x) and Python 3. Key R packages include: `tidyverse`, `seqinr`, `Biostrings`, `here`, `vegan`, `patchwork`, `cluster`, and `ggrepel`.
